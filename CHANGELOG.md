# Changelog

## 1.0.0

First release.

- `bitinz compress` compresses images and folders, keeps the format or converts JPG and PNG to WebP, and writes to `./bitinz-compressed` or in place.
- `bitinz login` / `bitinz logout` save and forget an API key.
- `bitinz mcp` runs an MCP server with a `compress_images` tool for AI agents.
- `Bitinz`, `compressFiles()` and `collectImages()` for Node.js.
